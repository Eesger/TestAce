# X.com Bookmark Archive

A curated knowledge base for AI development insights extracted from X.com bookmarks.

## Structure

- **Bookmarks/** — Clipped tweets and articles with summaries
- **Ideas/** — Extracted key concepts, techniques, and patterns
- **Themes/** — Clustered ideas and connections across bookmarks
- **Dashboard/** — Overview and search interface

## Setup

See [SETUP.md](../SETUP.md) for installation and template configuration.

## How to Use

1. Install Obsidian Web Clipper extension
2. Configure OpenRouter API key in Web Clipper settings
3. Use the templates provided:
   - Tweet template for X/Twitter posts
   - Article template for full articles and linked content
4. Clipped items automatically get AI summaries, key ideas, and tags
